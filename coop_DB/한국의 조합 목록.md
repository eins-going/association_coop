# 한국의 조합 목록

## 1. 문서의 역할

한국에서 ‘조합’이라 불리는 조직 전체를 체계적으로 관리하는 상위 레지스트리다.
협동조합뿐 아니라 공제조합, 노동조합, 주택·정비조합, 투자조합, 연구조합,
사업자조합, 계약형 조합과 공법상 조합의 세부 법정 형태를 포괄한다.

이 문서는 서로 다른 네 가지 층위를 연결한다.

| 층위 | 관리 대상 | 현재 기준 |
|---|---|---|
| **법정 조직군** | 법령상 조합 조직형의 상위 분류 | 근거법·법적 성격·주된 법정 목적 |
| **법적 형태** | 법률에 따라 실제로 존재하는 조합 | 민법·상법·특별법·공법상 조합 |
| **수집 분류** | 뉴스와 지식트리를 운영하는 검색 단위 | `news/`의 12개 범주 |
| **관측 단위** | CSV 한 행으로 확보된 조직·사업소·공시 | `data/rosters/`, `raw/statistics/` |

> **핵심 원칙:** 조합은 협동조합보다 넓은 개념이다. 현재 개별 명부가
> 협동조합 계열에 집중되어 있다는 사실은 LLM Wiki와 조합경영학의 연구범위가
> 협동조합에 한정된다는 뜻이 아니다.

### 1.1 전체 구조

```text
한국의 조합
├─ 법정 조직군: 근거법과 법적 성격이 유사한 상위 분류
├─ 법정 조직형: 법률이 설립·결성·인가·등록·인정하는 조직
├─ 법적 속성: 법인격 · 조합원 자격 · 의결 · 책임 · 존속기간
├─ 운영 범주: 뉴스 수집과 지식트리
└─ 개별 명부: 공개자료로 관찰 가능한 조직·사업소·공시
```

## 2. ‘조합’의 법적 의미

한국 법제에서 조합은 하나의 법적 형태가 아니다.

1. **계약으로서의 조합** — 민법상 조합과 상법상 익명조합·합자조합처럼
   당사자의 약정으로 성립하는 법률관계다.
2. **비법인 조직으로서의 조합** — 특별법이 결성·신고·등록과 내부기관을
   정하지만 법인격을 부여하지 않는 조직이다.
3. **법인으로서의 조합** — 개별 법률이 명시적으로 법인격을 부여하여 조합의
   재산과 책임을 조합원과 구분하는 조직이다.
4. **공법상 조직으로서의 조합** — 공공단체의 공동사무를 처리하거나 법률상
   사업시행·행정권한을 담당하는 조직이다.

이 네 설명은 배타적인 조직유형이 아니다. 계약형은 동시에 비법인이고 공법상
조합은 법인일 수 있으므로 성립근거, 법인격과 공법상 행정주체성을 별도 필드로
기록한다.

조합경영학은 이 조직들을 소유, 의결, 통제, 위험부담, 성과배분이라는 다섯
구조축으로 비교한다. 특정 유형의 이론을 다른 유형에 그대로 적용하지 않고,
공통 경영문제와 유형별 경영논리를 함께 분석한다.

## 3. 법령상 조합 조직군

`book/02-typology.md`의 법정 조직형 분류를 이 레지스트리의 상위 골격으로 사용한다.
현행 법령이 ‘조합’ 명칭으로 직접 설립·결성하게 하거나 인가·등록·신고·지정을
통해 별도 법적 지위를 부여한 조직만을 대상으로 한다.

| 조직군 | 판별 기준 | 주요 법정 조직형 |
|---|---|---|
| **민·상법상 조합** | 일반 사법상 조합계약 | 민법상 조합, 익명조합, 합자조합 |
| **협동조합 계열** | 상호이용과 협동을 위한 회원조직 | 기본법 협동조합, 농협, 수협, 산림조합, 신협, 생협, 중소기업협동조합 |
| **노동조합** | 근로자의 자주적 단결과 근로조건 유지·개선 | 일반·공무원·교원 노동조합 |
| **종사자·종업원조합** | 특정 직업활동 또는 종업원 지위 | 예술인조합, 우리사주조합 |
| **생산자·사업자조합** | 생산자·사업자의 공동경영·공동사업·업계대표 | 영농·영어조합법인, 한국해운조합, 염업조합, 운수사업자조합 |
| **전문직 공동사업조합** | 전문자격자의 공동 업무수행과 손익분배 | 법무조합 |
| **연구조합** | 기술개발과 연구성과의 공동 이용 | 산업기술연구조합 |
| **공제·보증조합** | 보증·융자·공제 또는 상호보험 | 업종별 공제조합, 선주상호보험조합 |
| **주택·정비·개발조합** | 권리자 등의 법정 사업시행조직 | 정비사업조합, 주택조합, 토지소유자조합 |
| **투자조합** | 특별법상 공동투자기구 | 개인·벤처·신기술사업·농식품 투자조합, 투자합자·익명조합 |
| **공공·행정조합** | 공공단체의 공동사무 또는 행정협력 | 지방자치단체조합, 지방세·기금관리·납세조합 |

### 3.1 분류 적용 원칙

- **조직군 수를 미리 정하지 않는다.** 현재 표의 수는 현행 법정 조직형을 묶은
  결과이며 새로운 법률군이 확인되면 추가한다.
- **각 조직형에는 주된 조직군 하나를 부여한다.** 설립근거, 조합원 자격과 주된
  법정 목적을 기준으로 판정한다.
- **겸영 기능은 별도 기록한다.** 한국해운조합은 사업자조합군에 두고 공제 겸영을
  기록한다.
- **준용규정으로 조직군을 정하지 않는다.** 영농·영어조합법인은 민법상 조합
  규정을 준용하지만 특별법상 법인이므로 민·상법상 조합군에 넣지 않는다.
- **단순 인용과 내부기관을 제외한다.** ‘조합’ 단어가 출현해도 독립된 조직형이
  아니면 조직형 수에 포함하지 않는다.
- **독립·하위·지정·경과형을 구분한다.** 중앙회, 내부기관, 상태명칭과 역사적
  조직을 현행 독립 조직형과 중복 계수하지 않는다.

## 8. 검증 및 해석 규칙

### 8.1 상태 기호

- **✅ 검증** — 공식 원문 또는 공식 목록을 확보하고 총수·단위를 대조함
- **△ 부분검증** — 공식 자료를 확보했으나 일부 페이지, 시점 또는 분류가 불완전함
- **⚠ 미검증** — 공식 출처 대조 전의 근사치 또는 일반적으로 알려진 수치
- **— 미구축** — 해당 자료체계에서는 아직 수집하지 않음

### 8.2 숫자를 사용할 때의 원칙

1. 법령 수와 조직 수를 구분한다.
2. 공시 건수와 설립·운영 조직 수를 구분한다.
3. 본점·지점·지부·사업소와 법인 수를 구분한다.
4. 현재 명부와 역사자료 명부를 구분한다.
5. 단일 조합은 조직 수보다 조합원 수와 사업규모를 본다.
6. 한시적 사업조합은 인가·사업·준공·해산 상태를 함께 본다.
7. 서로 다른 파생본의 숫자는 추출규칙을 확인하기 전 합치지 않는다.

## 9. 이론적 준거

[[Birchall-2022-조합원소유기업-분류]]의 member-owned business(MOB) 분류는
협동조합과 다른 회원기반 조직을 비교할 출발점을 제공한다. 농협·수협·산림조합은
생산자 소유와 상호금융이 결합된 복합체이고, 신협·새마을금고는 상호금융형 MOB,
사회적협동조합은 다중이해관계자 MOB로 볼 수 있다.

다만 노동조합·정비사업조합·투자조합·민상법상 조합을 모두 MOB로 설명할 수는
없다. MOB 분류는 협동조합 계열의 주요 이론으로 활용하되 이를 법령상 모든 조합
조직의 공통 본질로 확장하지 않는다.
